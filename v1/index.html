// Model Specifications

Built for edge, optimized for scale.

Aureven v1 is engineered as a lightweight language model that doesn't sacrifice capability for size. Click a spec for details.

01

Parameters

0.1B (100 million) parameters optimized for efficient inference.

Designed to run on consumer hardware and edge devices without requiring enterprise GPU clusters or extensive memory.

02

Training Data

Trained on diverse, high-quality datasets focused on agent reasoning and instruction following.

Emphasis on understanding commands, planning, and maintaining context through multi-step interactions for agentic behavior research.

03

Architecture

Transformer-based decoder-only architecture with modern optimizations.

Includes techniques like attention optimization, parameter sharing, and quantization-ready design for maximum efficiency and portability.
