At a glance

A focused model for experimentation.

Autarch is a small research prototype for studying image classification—not a validated diagnostic system.

01 · Architecture

Built from scratch

A convolutional neural network with 3.1 million parameters, created as a compact model-study project.

02 · Task

Dermoscopy images

Explores a binary classification task: melanoma versus other skin lesions in dermoscopy imagery.

03 · Intended use

Research only

For learning and experimentation. It has not been presented as clinically validated or suitable for patient care.

What this project is for
