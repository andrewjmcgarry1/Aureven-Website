# Security Policy

## Supported Versions
Only the latest release receives security fixes.

## Reporting a Vulnerability
Please do not open a public issue. Report privately via
GitHub's "Report a vulnerability" button in the Security tab,
or email andrewjmcgarry1@gmail.com.

Include: what you found, steps to reproduce, and the affected version.
I'll acknowledge within 7 days and keep you updated on the fix.

## Scope
In scope: code execution or unsafe model loading, exposed secrets,
vulnerable dependencies, privacy leaks in data or outputs.
Out of scope: general model inaccuracies or bias (open a normal issue).
